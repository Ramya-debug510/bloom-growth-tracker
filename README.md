# 🌱 BLOOM – Personal Growth & Productivity Tracker

BLOOM is a personal productivity and self-growth web application designed to help users build consistent habits, improve career skills, and manage daily routines.

## ✨ Features

- Daily Task Checklist
- Career Growth Tracker
- Python & Cybersecurity Learning Goals
- English Speaking Practice Tracker
- Phone Usage Tracking
- Self-Care Reminders
- Focus Timer
- Weekly Progress Chart
- Streak Counter & Achievement Badges
- Progressive Web App (PWA) Support

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- GitHub Pages
- Progressive Web App (PWA)
